💜 About Me

I’m a Web3 developer and open-source contributor interested in building software that is useful, verifiable, and secure.

My work spans smart contract development, decentralised applications, frontend engineering, and financial software. I’m especially interested in understanding what happens beneath the application layer — from Solidity execution to the Ethereum Virtual Machine.

* 🔐 Writing and testing smart contracts with Solidity and Foundry.
* ⚙️ Exploring Rust, virtual machines, and EVM internals.
* 🌐 Building web interfaces that connect users to blockchain applications.
* 🤝 Learning through open source, developer communities, and hands-on projects.
* 🧩 Interested in smart contract security, protocol engineering, and verifiable financial systems.

My approach: learn the fundamentals, build something real, test what I build, and keep improving.
